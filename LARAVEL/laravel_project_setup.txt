FRESH LARAVEL PROJECT — FULL SEQUENCE
================================================================

Step 1 — Go to your Laravel workspace
----------------------------------------------------------------
cd D:\Developer\Laravel


Step 2 — Create the project
----------------------------------------------------------------
laravel new project-name

Replace "project-name" with your project name.
Rules: lowercase, hyphens or underscores, no spaces.
Example:  laravel new blog-api

Prompts you will see:

  Prompt                                          Answer
  ----------------------------------------------  ---------
  Do you want to use a starter kit?               no
  Which frontend stack?                           blade
  Would you like to run the default migrations?   yes
  Testing framework                               pest
  Which AI agents to configure?                   pick one or Ctrl+C

If it asks for DB credentials during install:
  Host:      127.0.0.1
  Port:      3306
  Database:  <your database name>
  Username:  root
  Password:  <your MySQL root password>


Step 3 — Enter the project folder
----------------------------------------------------------------
cd project-name


Step 4 — Create the MySQL database
----------------------------------------------------------------
mysql -u root -p -e "CREATE DATABASE project_name CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

Note: use underscores, not hyphens, for DB names.
Example: project "blog-api"  ->  database "blog_api"


Step 5 — Configure .env for MySQL (if not auto-done)
----------------------------------------------------------------
notepad .env

Set these lines:

  DB_CONNECTION=mysql
  DB_HOST=127.0.0.1
  DB_PORT=3306
  DB_DATABASE=project_name
  DB_USERNAME=root
  DB_PASSWORD=your_mysql_root_password

Save and close.


Step 6 — Clear config and run migrations
----------------------------------------------------------------
php artisan config:clear
php artisan migrate

For a clean slate (drops all tables):
php artisan migrate:fresh


Step 7 — Start developing
----------------------------------------------------------------
composer run dev

This starts three things concurrently:
  - php artisan serve        -> http://127.0.0.1:8000
  - php artisan queue:listen -> background jobs
  - npm run dev              -> Vite hot-reload

Open http://127.0.0.1:8000 in your browser.

To stop:  Ctrl+C in that terminal.

================================================================
USEFUL ARTISAN COMMANDS
================================================================

  Action                          Command
  ------------------------------  ------------------------------------------
  List all routes                 php artisan route:list
  Interactive shell               php artisan tinker
  Create controller               php artisan make:controller PostController
  Create model + migration        php artisan make:model Post -m
  Create migration                php artisan make:migration create_posts_table
  Create seeder                   php artisan make:seeder PostSeeder
  Run migrations                  php artisan migrate
  Roll back last migration        php artisan migrate:rollback
  Wipe DB and re-migrate          php artisan migrate:fresh
  Wipe DB, re-migrate, seed       php artisan migrate:fresh --seed
  Clear all caches                php artisan optimize:clear
  Show Laravel environment        php artisan about
  Show database details           php artisan db:show
  Run tests                       php artisan test
  Format code (Pint)              ./vendor/bin/pint
